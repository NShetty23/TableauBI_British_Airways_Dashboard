# TableauBI_British_Airways_Dashboard
British_Airways_Review_Analysis
This Tableau dashboard provides a visual analysis of British Airways reviews from March 2016 to October 2023.
📊 Dashboard Features
Overall Rating Trends: Visualizes the average rating over time to monitor customer satisfaction.

Sentiment Breakdown: Displays distribution of positive, neutral, and negative reviews.

Class-wise Experience Analysis: Compares Economy, Premium Economy, Business, and First Class experiences.

Flight Route Insights: Highlights top and bottom-performing routes based on customer feedback.

Review Word Cloud: Visual representation of most commonly used words in reviews.

Interactive Filters: Segment data by date range, travel class, and route to explore specific patterns.
🛠️ Tools Used
Tableau (dashboard development and visualization)

Excel  (data source – reviews dataset)
